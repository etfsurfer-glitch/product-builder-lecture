프로그램 소개

💡 NSITE란?

NSITE는 N 블로그 활동(좋아요·댓글·이웃추가·서로이웃추가)을 자동으로 처리해주는 Windows 전용 데스크톱 프로그램입니다.
직접 블로그를 돌아다니며 손으로 하던 단순 반복 작업을 프로그램이 대신 수행하여 시간을 절약하고, 내 블로그의 유입과 이웃 수를 효율적으로 늘릴 수 있습니다.

핵심 기능

👍 좋아요

방문한 블로그 최신 글에 좋아요를 자동으로 누릅니다.

💬 댓글

직접 입력한 3개 문구 중 랜덤 선택, 또는 내장된 1,000개 댓글 중 자동 선택.

➕ 이웃추가

방문한 블로거를 내 이웃으로 자동 추가합니다.

🤝 서로이웃추가

서로이웃 신청 메시지를 자동 발송. 직접 입력 또는 내장 1,000개 메시지 중 자동 선택.

방문 대상 선택 (3가지 모드)

📂 분야별 HOT 블로그

카테고리(일상·요리·여행·IT 등 32개)별 인기 블로그를 방문합니다.

🔍 키워드별 HOT 블로그

검색어를 입력하면 해당 키워드의 인기 블로그를 방문합니다.

👥 이웃블로그 방문

내 N 계정에 등록된 이웃 블로그의 최신 글을 방문합니다.

프로그램 특징

  • ✓하루 최대 50개 블로그 처리 (안전 제한, 매일 자정 초기화)
  • ✓1~30개 목표 방문 수를 슬라이더로 자유롭게 설정
  • ✓한 번 방문한 블로그는 당일 재방문하지 않음 (중복 방지)
  • ✓자동화 실행 중 절전·화면꺼짐 자동 차단
  • ✓Chrome 세션이 끊겨도 자동 재시작 후 이어서 실행
  • ✓자동 업데이트 지원 (새 버전 감지 시 설치 안내)
  • ✓랜덤 댓글 1,000개 / 랜덤 서로이웃 메시지 1,000개 내장

설치 방법

홈페이지에서 설치 파일 다운로드

다운로드 페이지에서 최신 버전 설치 파일(NSITE_vX.X_setup.exe)을 받습니다.

설치 파일 더블클릭 실행

다운로드한 파일을 더블클릭합니다.

UAC 관리자 권한 허용

사용자 계정 컨트롤 창에서 예를 클릭합니다.

설치 마법사 진행

설치 경로 기본값(C:\Program Files\NSITE) 사용을 권장합니다. 설치 버튼을 눌러 완료합니다.

설치 완료 후 NSITE 실행

바탕화면 바로가기 또는 시작 메뉴에서 NSITE를 실행합니다.

(선택) 사용법 페이지 자동 열기

설치 완료 화면에서 "사용법 페이지 열기"를 체크하면 브라우저에서 이 가이드가 자동으로 열립니다.

🛡️
경고창조차 안 뜨고 실행이 완전히 막히는 경우 — 스마트 앱 컨트롤
Windows 스마트 앱 컨트롤이 켜져 있으면 SmartScreen 경고창 자체가 나타나지 않고 실행이 차단됩니다.
아래 링크를 주소창(또는 Win+R)에 입력하면 설정 화면이 바로 열립니다.
🛡️ 스마트 앱 컨트롤 설정 열기
windowsdefender://smartapp/

설정이 열리면 아래 이미지처럼 끄기를 선택하세요. 이후 NSITE를 다시 실행해주세요.

ℹ️
백신 프로그램이 설치를 차단하는 경우
보안 프로그램을 일시적으로 비활성화하거나 예외 경로(C:\Program Files\NSITE)로 등록 후 설치해주세요.

실행 & 로그인

NSITE 아이콘 더블클릭

바탕화면 바로가기 또는 시작 메뉴에서 실행합니다.

버전 확인 대기 (자동 진행)

로그인 화면 상단에서 버전 확인이 자동으로 진행됩니다.

✓ 최신버전 사용 중 — 로그인 버튼이 활성화됩니다.
↑ 새 버전 — 업데이트 후 이용 가능 — 업데이트를 먼저 진행해야 합니다. (로그인 불가)

사용 방법 단계별

STEP 1 · 기능 선택 (토글 스위치)

화면 상단의 토글 스위치 4개로 실행할 기능을 선택합니다. 원하는 기능만 골라 조합하거나 모두 켤 수 있습니다.

👍 좋아요

방문한 블로그 최신 글에 좋아요를 자동으로 누릅니다.

💬 댓글

설정한 문구 또는 내장 1,000개 중 랜덤으로 댓글을 남깁니다.

➕ 이웃추가

방문한 블로거를 이웃으로 자동 추가합니다.

🤝 서로이웃추가

서로이웃 신청 메시지를 자동 발송합니다.

ℹ️
이웃추가와 서로이웃추가는 동시에 사용할 수 없습니다.
이웃블로그 방문 모드에서는 이웃추가·서로이웃추가가 자동으로 비활성화됩니다.

STEP 2 · 댓글 문구 설정

댓글 토글을 켜면 댓글 문구 입력 영역이 펼쳐집니다.

✏️ 직접 입력
  • 3개의 댓글 문구를 직접 입력
  • 각 칸 클릭 시 입력 다이얼로그 열림
  • 저장 클릭 시 다음 실행에도 유지
  • 초기화로 기본 댓글 복원 가능
  • 작업 시 3개 중 하나 랜덤 선택
🎲 랜덤댓글 (추천)
  • 댓글 문구 위의 랜덤댓글 토글 ON
  • 내장된 1,000개 문장 중 방문마다 자동 선택
  • 직접 입력 칸은 비활성화됨
  • 별도 파일이나 인터넷 연결 불필요

STEP 3 · 서로이웃 메시지 설정

서로이웃추가 토글을 켜면 메시지 입력 영역이 펼쳐집니다.

✏️ 직접 입력
  • 서로이웃 신청 시 전달할 메시지 최대 2줄 입력
  • 저장 클릭 시 다음 실행에도 유지
  • 비워두면 메시지 없이 신청
🎲 랜덤메시지 (추천)
  • 메시지 입력 위의 랜덤메시지 토글 ON
  • 내장된 1,000개 메시지 중 방문마다 자동 선택
  • 직접 입력 칸은 비활성화됨

STEP 4 · 방문 대상 선택 (3가지 모드)

방문 설정 영역에서 카드를 클릭하여 모드를 선택합니다. 각 카드 우측 상단에 오늘 수집된 블로그 수가 표시됩니다.

🔍 키워드별 HOT 블로그

해당 키워드로 N에서 검색된 인기 블로그를 방문합니다.

👥 이웃블로그 방문

별도 설정 없이 클릭만 하면 됩니다.
현재 로그인된 N 계정의 이웃 블로그 최신 글을 방문합니다.
이 모드에서는 이웃추가·서로이웃추가가 자동으로 비활성화됩니다.

STEP 5 · 목표 방문 수 설정

🎚️ 슬라이더 조절 (1개 ~ 30개)

슬라이더를 좌우로 드래그하여 이번 실행에서 방문할 블로그 수를 설정합니다.

1개30개
⚠️
하루 최대 50개 제한
당일 50개 처리 시 작업이 자동 중단됩니다. 화면 하단 하루최대 바에서 오늘 남은 횟수를 실시간 확인할 수 있습니다. 매일 자정(00:00)에 자동 초기화됩니다.

STEP 6 · Chrome 열기 및 N 로그인

크롬 열기 버튼 클릭 → Chrome 자동 실행
열린 Chrome에서 N(네이버) 계정으로 로그인

이 N 계정이 자동화 작업의 주체가 됩니다.

로그인 완료 후 NSITE로 돌아오기

Chrome 창을 닫지 말고 유지한 채로 NSITE 프로그램으로 복귀합니다.

🔴
반드시 크롬 열기 버튼으로 실행한 Chrome에서 로그인하세요!
기존에 열려 있던 Chrome이 아닌, NSITE가 자동으로 연 브라우저에서만 자동화가 연결됩니다.

STEP 7 · 자동화 시작

✓ 좋아요 완료
✓ 댓글 완료
✓ 서로이웃 신청 완료
작업 완료 시 알림창 표시

"작업이 완료되었습니다" 알림창이 표시됩니다.

■ 긴급정지

이미 완료된 작업은 하루 사용량에 포함됩니다.

FAQ — 자주 묻는 질문

Q1. 프로그램이 실행되지 않아요 (스마트 앱 컨트롤). ▼
Windows 스마트 앱 컨트롤이 켜져 있으면 SmartScreen 경고창조차 표시되지 않고 실행이 완전히 차단됩니다.

아래 링크를 주소창(Win+R)에 입력하면 설정이 바로 열립니다.
windowsdefender://smartapp/
설정에서 끄기를 선택한 뒤 NSITE를 다시 실행해주세요.

Q2. 로그인 버튼이 회색으로 비활성화되어 있어요. ▼
버전 확인이 완료되어야 로그인 버튼이 활성화됩니다. 잠깐 기다려주세요. 새 버전이 감지된 경우에는 업데이트를 먼저 진행해야 합니다.
Q3. "최신 버전으로 업데이트 후 이용 가능합니다" 메시지가 뜹니다. ▼
현재 설치된 버전이 구버전입니다. 업데이트 팝업에서 예를 눌러 업데이트해주세요. 업데이트 후 자동으로 재시작됩니다.
Q4. Chrome이 열리지 않거나 오류가 발생합니다. ▼
Google Chrome이 설치되어 있는지 확인해주세요. 설치되어 있다면 최신 버전으로 업데이트 후 다시 시도해주세요. (Chrome 설정 → Chrome 정보 → 업데이트 확인)
NSITE는 Chrome 버전에 맞는 드라이버를 자동으로 설치합니다.
Q5. 자동화 실행 중 Chrome이 갑자기 꺼졌습니다. ▼
NSITE가 자동으로 감지하고 재시작을 안내합니다. 팝업이 뜨면 Chrome에서 N에 재로그인 후 확인을 눌러주세요. 이전에 방문한 블로그는 건너뛰고 이어서 실행됩니다.
Q6. 하루 50개 제한은 언제 다시 채워지나요? ▼
매일 자정(00:00)에 자동으로 초기화됩니다. 프로그램을 재시작하지 않아도 됩니다.
Q7. 방문했던 블로그에 또 방문하는 것 같아요. ▼
방문 기록은 프로그램이 실행 중인 동안만 유지됩니다. 프로그램을 껐다 켜면 방문 기록이 초기화됩니다.
Q8. 댓글·서로이웃 메시지를 저장했는데 다음에 사라졌습니다. ▼
관리자 권한으로 실행하지 않으면 저장이 안 될 수 있습니다. 항상 관리자 권한으로 실행해주세요.
Q9. 무료 회원도 쓸 수 있나요? ▼
무료(Free) 플랜은 이용이 제한됩니다. Pro 플랜 활성화 후 이용 가능합니다. 관리자에게 문의해주세요.
Q10. N 계정이 활동 제한을 받았습니다. ▼
자동화 사용으로 인한 계정 제재 등의 결과는 이용자 책임입니다. 하루 제한 내에서 적절히 사용해주세요.
Q11. 이웃블로그 방문 모드에서 이웃추가가 비활성화됩니다. ▼
정상입니다. 이웃블로그 방문 모드는 이미 이웃인 블로거를 방문하는 모드이므로 이웃추가·서로이웃추가가 자동으로 비활성화됩니다.
Q12. 분야별/키워드별 카드에 "현재수집: 0개"라고 표시됩니다. ▼
아직 블로그를 수집하지 않은 상태입니다. ▶ 시 작을 누르면 자동으로 블로그 목록을 수집한 뒤 작업이 시작됩니다.
Q13. 랜덤댓글/랜덤메시지는 어떻게 동작하나요? ▼
프로그램 내부에 1,000개의 댓글 문장과 1,000개의 서로이웃 신청 메시지가 내장되어 있습니다. 랜덤 토글을 켜면 블로그 방문마다 다른 문장이 자동으로 선택됩니다. 별도 파일이나 인터넷 연결 없이 동작합니다.
Q14. 같은 컴퓨터에서 여러 계정을 사용할 수 있나요? ▼
한 번에 하나의 N 계정만 사용 가능합니다. 계정 공유 및 다중 계정 사용은 이용약관에 위배됩니다.

1

목적

본 약관은 RUNTO (이하 "회사")가 제공하는 자동화 프로그램 및 관련 서비스(이하 "서비스")의 이용과 관련하여 회사와 이용자 간의 권리, 의무 및 책임사항을 규정함을 목적으로 합니다.

2

정의

  • "서비스"란 회사가 제공하는 자동화 프로그램 및 관련 기능을 의미합니다.
  • "이용자"란 본 약관에 동의하고 서비스를 이용하는 개인 또는 법인을 의미합니다.
3

약관의 효력 및 변경

  • 본 약관은 서비스를 이용하고자 하는 모든 이용자에게 적용됩니다.
  • 회사는 필요한 경우 약관을 변경할 수 있으며, 변경된 약관은 공지 후 효력이 발생합니다.
  • 이용자는 변경된 약관에 동의하지 않을 경우 서비스 이용을 중단할 수 있습니다.
4

서비스의 제공

  • 회사는 자동화 프로그램 및 관련 기능을 제공합니다.
  • 서비스는 운영상 필요에 따라 변경 또는 중단될 수 있습니다.

  • 이용자는 서비스를 관련 법령 및 각 플랫폼의 정책에 따라 이용해야 합니다.
  • 이용자는 서비스를 악용하거나 타인의 권리를 침해하는 행위를 해서는 안 됩니다.
  • 이용자는 자동화 기능 사용 시 발생할 수 있는 모든 결과에 대해 책임을 집니다.
6

회사는 다음의 경우 이용자의 서비스 이용을 제한할 수 있습니다.

  • 서비스의 정상적인 운영을 방해하는 경우
  • 법령 또는 본 약관을 위반하는 경우
  • 비정상적이거나 과도한 자동화 사용이 확인된 경우
  • 계정 공유 또는 다중 계정 사용 등 부정 이용이 의심되는 경우

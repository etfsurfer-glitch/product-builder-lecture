Nself 사용 가이드

네이버 블로그 자동화 프로그램 Nself의 모든 기능을 단계별로 안내합니다.

1

시작하기

💡 프로그램 소개

Nself는 네이버 블로그 방문, 좋아요, 댓글, 이웃추가 등을 자동으로 처리해주는 Windows 전용 자동화 도구입니다.

시스템 요구사항

🖥️
운영체제
Windows 10 / 11
🌐
브라우저
Chrome 설치 필수

프로그램 실행 방법

Nself.exe 파일을 더블클릭하여 실행

다운로드한 파일을 실행합니다.

UAC 관리자 권한 팝업이 나타나면 예 클릭

프로그램이 정상 작동하려면 관리자 권한이 필요합니다.

Windows SmartScreen 경고 처리

경고 화면이 나타나면 아래 순서대로 진행하세요.

⚠️
Windows SmartScreen 경고가 표시되는 경우
개인 개발자 프로그램의 경우 Microsoft 인증서가 없어 경고가 나타날 수 있습니다. 이는 정상적인 현상입니다.

2

회원가입 & 로그인

회원가입

회원가입 버튼 클릭

프로그램 하단의 회원가입 버튼을 클릭합니다.

이메일 / 비밀번호 입력

사용할 이메일과 비밀번호를 입력합니다.

이용약관 스크롤 후 동의 체크

이용약관을 끝까지 스크롤한 뒤 동의 체크박스를 체크합니다.

가입하기 클릭

모든 정보 입력 후 가입하기 버튼을 클릭합니다.

🔴
이메일 인증 필수!
가입 후 반드시 등록한 이메일의 받은 편지함을 확인하고 인증을 완료하세요. 인증하지 않으면 로그인이 불가합니다.

로그인

이메일 / 비밀번호 입력

가입 시 등록한 이메일과 비밀번호를 입력합니다.

로그인 버튼 클릭

아이디/비밀번호 저장 체크 시 다음 실행부터 자동 입력됩니다.

ℹ️
Pro 플랜 안내
Nself의 모든 기능은 Pro 플랜에서만 이용 가능합니다. Free 플랜 사용자는 결제가 필요합니다.
3

크롬 브라우저 설정

프로그램에서 크롬 열기 버튼 클릭

자동화 전용 크롬 브라우저가 열립니다.

열린 크롬에서 네이버 로그인

naver.com에 접속하여 자동화에 사용할 네이버 계정으로 로그인합니다.

로그인 완료 후 프로그램으로 복귀

로그인이 완료되면 크롬 창은 그대로 두고 Nself 프로그램으로 돌아옵니다.

⚠️
반드시 프로그램에서 연 크롬에서 로그인하세요!
기존에 열려있는 크롬이 아닌, 크롬 열기 버튼으로 열린 브라우저에서 로그인해야 자동화가 정상 작동합니다.

🔥 인기글 모드

네이버에서 현재 인기 있는 블로그를 자동으로 수집하여 방문합니다. 별도 설정이 필요 없으며, 트렌드에 맞는 블로그를 효율적으로 방문할 수 있습니다.

👥 이웃블로그 모드

내 이웃으로 등록된 블로그를 순차적으로 방문합니다. 이웃 관리와 소통을 자동화하는 데 유용합니다.

🎚️ 방문 수 슬라이더

슬라이더를 조절하여 한 번에 방문할 블로그 수를 설정합니다. 수가 많을수록 실행 시간이 길어집니다.

5

기능 설정

4개의 토글 스위치로 원하는 기능을 ON/OFF 할 수 있습니다.

👍 좋아요

방문한 블로그 포스트에 자동으로 좋아요를 누릅니다.

💬 댓글

등록한 댓글 문구 중 랜덤으로 하나를 선택하여 자동 작성합니다.

➕ 이웃추가

일방 이웃을 자동으로 신청합니다.

🤝 서로이웃추가

서로이웃 신청과 함께 메시지를 입력할 수 있습니다. (최대 2줄)

조합별 동작 방식

조합 좋아요 댓글 이웃추가 동작 순서
좋아요 단독 ✔ — — 좋아요 실행
댓글 단독 — ✔ — 댓글 작성
좋아요 + 댓글 ✔ ✔ — 1패스 동시 처리
전체 기능 ✔ ✔ ✔ 좋아요+댓글 → 이웃추가
ℹ️
이웃추가 / 서로이웃추가는 동시 선택 불가
두 기능은 상호 배타적이며, 활성화 시 항상 마지막에 실행됩니다.
6

댓글 문구 설정

댓글 토글을 ON으로 변경

댓글 기능을 켜면 하단에 댓글 문구 설정 섹션이 나타납니다.

연필 아이콘 ✏️ 클릭

댓글 입력 팝업이 열립니다.

댓글 1~3개 등록

최대 3개의 댓글을 미리 등록할 수 있으며, 실행 시 랜덤으로 하나가 선택됩니다.

💡 댓글 예시
댓글 1: "좋은 글 잘 읽었습니다! 😊"
댓글 2: "유익한 정보 감사합니다~"
댓글 3: "글이 정말 도움이 됐어요 👍"
💡
팁
자연스러운 다양한 문구를 등록하면 자동 댓글이 더 자연스럽게 보입니다.

주의사항 & FAQ

주의사항

🚨
반드시 지켜주세요!
  • 크롬 브라우저에서 네이버 로그인은 필수입니다.
  • 실행 중 크롬 창을 닫지 마세요.
  • 과도한 자동화는 네이버 계정 제재 위험이 있습니다.
✅
하루 적정 사용량 권장
  • 이웃추가: 10~20개
  • 좋아요: 50~100개
  • 과도하게 사용하지 않으면 계정 제재 위험이 크게 줄어듭니다.

자주 묻는 질문

Q. 이웃추가 버튼이 없다고 나와요 ▼
이미 이웃으로 등록된 블로그이거나 비공개 블로그인 경우 이웃추가 버튼이 표시되지 않을 수 있습니다. 이 경우 해당 블로그는 자동으로 건너뜁니다.
Q. 크롬이 안 열려요 ▼
Chrome 브라우저가 PC에 설치되어 있는지 확인하세요. 설치되어 있지 않다면 Google Chrome 공식 사이트에서 다운로드 후 설치해주세요.
Q. 로그인이 안 돼요 ▼
이메일 인증이 완료되었는지 확인하세요. 가입 시 등록한 이메일의 받은 편지함(스팸 폴더 포함)을 확인하고 인증 링크를 클릭해주세요.
Q. SmartScreen 경고가 떠요 ▼
Windows SmartScreen 경고 창에서 추가 정보를 클릭한 뒤 실행 버튼을 클릭하면 프로그램이 정상적으로 실행됩니다. 이는 개인 개발자 프로그램에서 나타나는 정상적인 경고입니다.

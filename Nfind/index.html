1기기 1계정 정책

Nfind는 한 계정당 하나의 기기에서만 사용할 수 있습니다. 최초 로그인 시 현재 기기가 계정에 등록됩니다. 다른 기기에서 로그인을 시도하면 접속이 차단됩니다.

기기 변경이 필요한 경우 고객센터로 문의해주세요.

단지 검색

기본 검색

검색어 입력
화면 왼쪽 검색창에 단지명 또는 지역명(동 이름)을 입력합니다.
검색 실행
Enter 키 또는 [검색] 버튼을 클릭합니다.
단지 선택
결과 목록에서 원하는 단지를 클릭합니다.
💡
검색 예시: "래미안", "반포동", "영등포구 당산"

단지 목록

  • 검색 결과는 단지명 · 주소 형태로 표시됩니다.
  • 단지를 클릭하면 우측 선택된 단지 정보 패널에 단지명, 주소, 세대수, 입주, 면적범위가 표시됩니다.

매물 추출

단지를 선택한 후 [⬇ 매물 추출] 버튼을 클릭합니다.

  • 추출 중에는 진행률 표시줄이 표시됩니다.
  • 추출이 완료되면 매물 테이블에 결과가 표시됩니다.
  • 추출된 매물 건수와 완료 시각이 하단 상태바에 표시됩니다.

필터 및 정렬

필터

매물 테이블 위 필터 바에서 다음 조건으로 목록을 좁힐 수 있습니다.

필터 항목설명
거래 구분전체 / 매매 / 전세 / 월세
동특정 동 번호 입력 (예: 101)
매물번호 검색매물번호 또는 설명 텍스트 검색
ℹ️
[적용] 버튼 또는 Enter 키로 필터를 적용하고, [초기화] 버튼으로 전체 해제합니다.

정렬

각 컬럼 헤더를 클릭하면 해당 컬럼 기준으로 오름차순 / 내림차순 정렬이 가능합니다. ▲ · ▼ 아이콘으로 현재 정렬 방향을 확인할 수 있습니다.

동호수 묶기

필터 바 오른쪽의 동호수 묶기 토글을 켜면, 같은 동·호수에 여러 매물이 있는 경우 하나로 묶어 표시합니다. 보라색 굵게 표시된 행이 묶인 항목입니다.

  • 만료 후 로그인 시도 시 안내 메시지와 함께 고객센터 연결 버튼이 표시됩니다.

FAQ

이메일 인증 메일이 오지 않아요.▼
스팸함을 먼저 확인해주세요. 스팸함에도 없다면 5분 후에 다시 시도하거나, 이메일 주소를 잘못 입력했을 수 있으니 재가입을 시도해주세요.
"이미 가입된 이메일입니다" 오류가 떠요.▼
해당 이메일로 이미 가입된 계정이 있습니다. 이메일 인증을 완료했는지 확인 후 로그인하세요.
"이 기기에는 이미 등록된 계정이 있습니다" 메시지가 뜹니다.▼
현재 컴퓨터에 다른 계정이 이미 등록되어 있습니다. Nfind는 1기기 1계정 정책을 적용하고 있으므로, 해당 기기에서는 등록된 계정으로만 사용하실 수 있습니다. 계정 변경이 필요하면 고객센터로 문의해주세요.
"등록되지 않은 기기에서 로그인을 시도했습니다" 오류가 떠요.▼
최초 로그인한 기기와 다른 컴퓨터에서 로그인을 시도하고 있습니다. 기기 변경을 원하시면 고객센터에 문의해주세요.
검색 결과가 안 나와요.▼
단지명 또는 지역명을 더 간단하게 입력해보세요. 예를 들어 "래미안 아파트" 대신 "래미안"으로, "강남구 역삼동" 대신 "역삼동"으로 검색해보세요.
매물 추출 중 "추출 중 오류 발생" 메시지가 떠요.▼
인터넷 연결 상태를 확인하고 다시 시도해주세요. 반복 발생 시 고객센터로 문의해주세요.
Excel/CSV 저장 후 파일이 어디 있나요?▼
저장 후 해당 폴더가 자동으로 탐색기에서 열립니다. 기본 저장 위치는 Windows 문서(Documents) 폴더입니다.
Excel에서 열었을 때 한글이 깨져요.▼
CSV 파일은 UTF-8 BOM 형식으로 저장되어 Excel에서 별도 설정 없이 바로 열립니다. 만약 깨짐이 발생한다면 Excel에서 직접 파일 열기 → 인코딩: UTF-8 선택 후 열어보세요.
비밀번호를 잊어버렸어요.▼
현재 Nfind는 이메일/비밀번호 직접 재설정 기능을 제공하지 않습니다. 고객센터로 문의해주세요.
구독이 만료됐는데 연장하고 싶어요.▼
로그인 시도 화면의 [고객센터] 버튼 또는 홈페이지를 통해 문의해주세요.
프로그램 업데이트는 어떻게 하나요?▼
로그인 화면에서 최신 버전이 아닌 경우 자동으로 감지되며, [⬇ 업데이트] 버튼이 표시됩니다. 버튼을 클릭하면 다운로드 페이지로 이동합니다. 기존 프로그램을 삭제하지 않고 새 설치 파일을 실행하면 자동으로 업데이트됩니다.

스마트 앱 컨트롤 문제 해결

Windows 11에는 스마트 앱 컨트롤(Smart App Control) 기능이 있습니다. 이 기능이 활성화되어 있으면 개인 개발사의 서명되지 않은 프로그램 실행을 차단할 수 있습니다.

다음과 같은 증상이 나타날 수 있습니다:

  • 설치 파일 실행 시 아무 반응 없이 차단됨
  • "Windows의 PC 보호" 화면이 표시되지 않고 바로 차단
  • 설치는 됐으나 프로그램 실행 시 차단됨

해결 방법 1 — 스마트 앱 컨트롤 끄기 (권장)

설정 열기
Windows 시작 메뉴 → 설정(⚙)을 엽니다.
보안 메뉴 이동
개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤로 이동합니다.
스마트 앱 컨트롤 설정
스마트 앱 컨트롤 설정 링크를 클릭합니다.
끄기 선택
끄기를 선택합니다.
재실행
Nfind 설치 파일을 다시 실행합니다.

해결 방법 2 — 파일 속성에서 차단 해제

설치 파일이 다운로드 시 차단 표시된 경우 개별 해제가 가능합니다.

파일 속성 열기
내려받은 Nfind_Setup_v1.2.exe 파일에서 마우스 오른쪽 버튼 → 속성을 클릭합니다.
차단 해제 체크
일반 탭 하단에 "이 파일은 다른 컴퓨터에서 가져온 것입니다..." 문구와 함께 [차단 해제] 체크박스가 표시됩니다. 체크한 뒤 [확인]을 클릭합니다.
재실행
설치 파일을 다시 실행합니다.

해결 방법 3 — "추가 정보" 클릭으로 실행 허용

"Windows의 PC 보호" 경고 화면이 표시되는 경우:

[추가 정보] 클릭
경고 화면에서 [추가 정보]를 클릭합니다.
[실행] 클릭
[실행] 버튼이 나타나면 클릭합니다.

Chapter 01
프로그램 설치 및 최초 실행
1설치하기
1받은 설치파일 NWriting_v1.0_Setup.exe를 더블클릭합니다.
2"이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 예를 클릭합니다.
3설치 화면의 안내대로 다음 → 다음 → 설치를 클릭합니다.
4설치 완료 화면에서 안내를 확인하고 마침을 클릭합니다.
5설치 후에는 바탕화면의 N Writing 블로그 자동화 아이콘으로 실행합니다.
⚠️ 설치 완료 시 자동 실행되지 않습니다. 반드시 바탕화면 아이콘을 직접 클릭하세요.
2Gemini API 키 발급 (최초 1회)
이 프로그램은 Google Gemini AI를 이용해 블로그 글을 생성합니다. API 키가 없으면 글을 작성할 수 없습니다.
1구글 계정으로 https://aistudio.google.com에 접속합니다.
2좌측 메뉴에서 Get API key → Create API key를 클릭합니다.
3생성된 키(AIzaSy...로 시작)를 복사해 둡니다.
4이 키는 프로그램 실행 후 Gemini Key 란에 붙여넣기 합니다.
Chapter 02
로그인 화면
1로그인 순서
1프로그램이 열리면 잠시 버전 확인 중... 메시지가 표시됩니다.
2버전 확인이 완료되면 로그인 버튼이 활성화됩니다.
3발급받은 이메일과 비밀번호를 입력합니다.
4로그인 버튼을 클릭합니다.
2로그인이 안 될 때
메시지원인해결 방법
버전을 확인할 수 없습니다인터넷 연결 문제인터넷 연결 확인 후 재시작
업데이트가 필요합니다구버전 사용 중업데이트 버튼 클릭 후 재설치
PRO 플랜 전용입니다FREE 계정으로 로그인관리자에게 PRO 업그레이드 문의
이메일 또는 비밀번호 오류잘못된 정보 입력이메일/비밀번호 재확인
3회원가입 (계정이 없는 경우)
1로그인 화면 하단의 회원가입 버튼을 클릭합니다.
2이메일, 비밀번호, 전화번호를 입력합니다.
3PRO 플랜을 사용하려면 관리자에게 받은 초대 코드를 입력합니다.
4가입하기 버튼을 클릭합니다.
Chapter 03
탭 1 — 일반 블로그 작성
전체 흐름: 키워드 입력 → 설정 확인 → 작성 시작 → (네이버 로그인) → 자동 발행
1STEP 1 — 키워드 입력

화면 왼쪽의 키워드 목록 표에 블로그로 작성할 주제를 입력합니다.

→표의 빈 칸을 클릭 후 키워드 입력 (예: 제주도 여행, 다이어트 식단)
→Tab 또는 Enter 키로 다음 칸 이동 · 최대 30개 입력 가능
→엑셀 A열에 키워드 입력 후 📊 엑셀로 등록 버튼으로 일괄 등록 가능
→💾 저장: 다음 실행 시 자동 불러오기 / 🗑 초기화: 전체 삭제
2STEP 2 — 내 블로그 글 수집 (선택사항)
블로그 글 안에 내 이전 게시글 링크를 자동 삽입하는 기능입니다. 검색 노출에 도움이 됩니다.
1주소 칸에 내 네이버 블로그 주소를 입력합니다. (예: https://blog.naver.com/내아이디)
2수집 시작 버튼을 클릭합니다.
3수집 완료 후 목록에서 게시글 제목 확인 → 저장 버튼 클릭
체크박스 "본인 게시글 중 랜덤으로 2개의 링크가 적용됩니다"가 체크되어 있어야 작동합니다. 내부 링크를 원하지 않으면 체크를 해제하세요.
3STEP 3 — 오른쪽 설정 확인
글감기간 추천: 1주일
AI가 참고할 인터넷 자료의 기간 설정. 오늘 / 1주일 / 1달 / 3달 / 6달 / 1년 선택 가능
우선순위 추천: 관련도순
글감 수집 시 참고 순서. 관련도순(기본값) 또는 최신순 선택
아이디 / 비밀번호
네이버 블로그 자동 로그인용 정보 입력. 기억 버튼으로 저장 · 보이기 버튼으로 확인 가능
⚠️ 비밀번호는 내 컴퓨터에만 저장됩니다. 외부로 전송되지 않습니다.
Gemini Key
발급받은 API 키 붙여넣기 → 저장 버튼. 한 번 저장하면 다음 실행 시 자동 불러오기
발행 설정 처음엔: 임시저장 권장
임시저장: 네이버 블로그 임시저장함에 저장 (검토 후 수동 발행)
바로등록: 작성 즉시 블로그에 공개 게시
4STEP 4 — 이미지 방식 선택
AI만 기본값
Gemini AI가 글 내용에 맞는 이미지 자동 생성. 생성 개수 1~10개 설정 가능 (기본 3개). 이미지 1개당 약 200원 비용 발생
키워드 이미지
인터넷에서 키워드 관련 이미지 검색 후 삽입. 저작권은 사용자 본인 확인 및 책임. AI 이미지 추가 옵션 체크 시 AI 이미지 1개 추가 삽입 (약 200원)
카드뉴스
각 단락마다 카드뉴스 형식 이미지 자동 생성. 카드뉴스 양식을 미리 제작한 후 사용 가능
5STEP 5 — 작성 시작
1모든 설정 완료 후 ▶ 작성 시작 버튼 클릭
2아래 로그 영역에 진행 상황이 실시간 표시됨
3브라우저 창이 자동으로 열리며 네이버 로그인 시도
보안 인증(캡챠, 문자 인증)이 나타나면: 브라우저에서 직접 인증 완료 후 화면의 ✔ 로그인 완료 버튼 클릭
⚠️ ⏹ 긴급정지 버튼으로 즉시 중단 가능. 이미 발행된 글은 취소되지 않습니다.
Chapter 04
탭 2 — 연예스타 블로그 작성

연예인, 인물 관련 블로그를 전문으로 작성하는 탭입니다.

항목일반 블로그연예스타 블로그
이미지 방식선택 가능키워드 이미지 8장 고정
글쓰기 스타일사용자 설정"바라봄" 연예 블로거 스타일
카테고리 설정있음없음
내 블로그 링크선택 가능선택 가능
⚠️ 중요: 연예스타 탭에서 수집되는 키워드 이미지(인물 사진 등)에 대한 저작권 책임은 전적으로 사용자 본인에게 있습니다. 이미지 사용 전 저작권 여부를 반드시 직접 확인하시기 바랍니다.
기본 사용 방법은 일반 블로그 탭과 동일합니다. STEP 1~5를 그대로 따라하면 됩니다.
Chapter 05
공통 기능 — 글쓰기 설정

⚙ 글쓰기 설정 버튼을 클릭하면 AI가 글을 쓰는 스타일을 상세하게 조정할 수 있습니다.

글쓰기 스타일
블로그 글의 전반적인 분위기와 문체 설정
예: 친근하고 일상적인 말투, 전문적인 정보성 글, 감성적인 에세이체 등
글감 재료
AI가 참고할 추가 지시사항 입력
1⚙ 글쓰기 설정 버튼 클릭
2원하는 스타일 항목 수정
3저장 버튼 클릭 → 다음 작성 시부터 적용
처음에는 기본값으로 사용하고, 글 스타일이 마음에 들지 않을 때 조정해 보세요.
Chapter 06
공통 기능 — 카드뉴스 제작기

🃏 카드뉴스 제작 버튼을 클릭하면 블로그에 삽입할 카드뉴스 이미지 양식을 만들 수 있습니다.

이미지 위에 텍스트(단락 내용)가 인쇄된 형식. 인스타그램 카드뉴스와 유사한 형태입니다.
1🃏 카드뉴스 제작 버튼 클릭
2이미지 선택 버튼으로 배경 이미지 선택 (권장: 가로형 4:3 비율)
3이름 칸에 양식 이름 입력 (예: 봄배경, 심플화이트)
4미리보기 확인 — 파란 선을 드래그해 이미지·텍스트 영역 비율 조절 가능
5저장 버튼 클릭 → 갤러리에 표시
→카드뉴스 적용 방법
1이미지 방식에서 카드뉴스 선택
2저장된 양식 목록에서 사용할 양식 클릭
3이후 작성 시 각 단락마다 선택한 양식으로 카드뉴스 이미지 자동 생성

📄 프롬프트 편집 버튼을 클릭하면 AI에게 전달하는 지시문(프롬프트)을 직접 볼 수 있습니다.

기본 프롬프트 수정 불가

글의 분위기와 문체 지시문
글감 프롬프트 수정 가능
글감 수집 방식 지시문
⚠️ 기본 프롬프트는 잘못 수정하면 프로그램이 오작동할 수 있습니다. 수정이 필요한 경우 관리자에게 문의하세요.
Chapter 08
자주 묻는 질문 (FAQ)
Q. 처음에 어떤 설정부터 해야 하나요?▼
① Gemini API 키 저장 → ② 네이버 아이디/비밀번호 입력 후 기억 → ③ 키워드 1~2개 입력 → ④ 발행설정 "임시저장" 선택 → ⑤ 작성 시작 순서로 테스트해 보세요.
Q. 브라우저가 열렸는데 멈춰 있어요.▼
네이버 보안 인증(캡챠, 문자 인증)이 필요한 상황입니다. 브라우저에서 직접 인증을 완료한 후 ✔ 로그인 완료 버튼을 클릭하세요.
Q. 글이 하나도 발행되지 않았어요.▼
로그 창의 빨간 오류 메시지를 확인하세요. 주로 ① Gemini API 키 미입력/오류 ② 네이버 로그인 실패 ③ 키워드 미입력 중 하나입니다.
Q. Gemini API 키는 돈이 드나요?▼
구글에서 제공하는 무료 사용량 한도 내에서는 무료입니다. AI 이미지 생성(Imagen)은 이미지 1개당 약 200원 비용이 발생하므로, 이미지 방식을 키워드 이미지로 설정하면 이미지 비용이 발생하지 않습니다.
Q. 네이버 아이디를 여러 개 사용하고 싶어요.▼
현재 버전은 아이디 1개만 지원합니다. 다른 아이디를 사용하려면 아이디/비밀번호를 바꾸고 기억 버튼을 다시 눌러 저장하세요.
Q. 업데이트가 있다고 떠요.▼
로그인 화면에서 업데이트 버튼을 클릭하면 최신 설치파일이 자동으로 다운로드되고 설치가 시작됩니다.
Q. 프로그램이 갑자기 종료됐어요.▼
임시저장 모드로 작성 중이었다면 네이버 블로그 임시저장함에 저장된 글이 있을 수 있습니다. 바로등록 모드라면 로그를 확인해 몇 번째 키워드까지 발행됐는지 확인하세요.
